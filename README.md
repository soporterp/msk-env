## Estructura del proyecto

```
compose/     -> Docker Compose
schemas/     -> Esquemas SQL/JS
init/        -> Scripts de inicialización
lib/         -> Librerías comunes
scripts/     -> Administración del laboratorio
```

## Uso

```bash
./scripts/db-up.sh

./scripts/provision.sh

./scripts/db-status.sh

./scripts/db-down.sh
```
